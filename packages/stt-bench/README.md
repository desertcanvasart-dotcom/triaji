# @triaji/stt-bench

Arabic STT provider benchmark harness for Triaji.

Compares **Deepgram Nova-2, Deepgram Nova-3, OpenAI gpt-4o-transcribe, OpenAI gpt-4o-mini-transcribe, Groq whisper-large-v3, and ElevenLabs Scribe** on Egyptian-Arabic medical speech. Produces a markdown report with WER, CER, latency, and cost per provider — for both **batch** and **streaming** modes.

## Quick start

```bash
# 1. Set API keys in .env (workspace root) or packages/stt-bench/.env.local
#    Any subset works — missing providers are skipped, not errored.
echo 'DEEPGRAM_API_KEY=...'   >> .env
echo 'OPENAI_API_KEY=...'     >> .env
echo 'GROQ_API_KEY=...'       >> .env
echo 'ELEVENLABS_API_KEY=...' >> .env

# 2. Install deps
pnpm install --filter @triaji/stt-bench

# 3. Generate seed audio via ElevenLabs TTS (one-time, ~2 minutes)
pnpm --filter @triaji/stt-bench seed:tts

# 4. Run benchmark
pnpm --filter @triaji/stt-bench bench                 # batch only
pnpm --filter @triaji/stt-bench bench:stream          # streaming only
pnpm --filter @triaji/stt-bench bench -- --mode both  # both

# 5. Open the report
open packages/stt-bench/results/report-*.md
```

## What the seed audio is — and isn't

`pnpm seed:tts` generates 20 Egyptian-Arabic medical-complaint audio clips by synthesizing the texts in `fixtures/seeds/egyptian-medical.json` via ElevenLabs Multilingual v2.

**These clips are studio-clean TTS, not phone-noisy real speech.** They're useful for:
- Smoke-testing the harness wiring (does each provider return text?)
- *Relative* comparisons between providers (provider A vs B on the same clean input)

They are **not** representative of:
- Phone-line audio quality (8kHz mulaw, codec artifacts)
- Real Egyptian patient speech (older speakers, regional accents, emotional state)
- Background noise (TV in the background, traffic, multiple speakers)

The numbers you get will be much better than production. Treat them as a ceiling, not a forecast.

## Upgrading to real samples

Drop real Twilio recordings into `fixtures/audio/` (any of `.wav`, `.mp3`, `.m4a`, `.ogg`, `.opus`) and add entries to `fixtures/samples.json`:

```json
{
  "samples": [
    {
      "id": "real-001-mr-ahmed-chest-pain",
      "audio": "audio/real-001.wav",
      "reference": "السلام عليكم، أنا حاسس بألم في صدري…",
      "description": "Real patient, 55yo male, Cairo",
      "dialect": "egyptian_cairene"
    }
  ]
}
```

Reference transcripts can be rough — the Arabic normalizer (`src/metrics/normalize-arabic.ts`) handles diacritic/spelling variation so you don't need perfectly clean references. Aim for words-correct, not orthography-correct.

For streaming benchmarks, audio **must be a 16-bit PCM WAV** at any sample rate ≥ 8kHz. The harness downsamples and μ-law encodes for Twilio-faithful streaming replay. (For batch, any format works.)

## Architecture

```
packages/stt-bench/
├── src/
│   ├── providers/
│   │   ├── types.ts                 SttProvider interface
│   │   ├── index.ts                 Factory — reads env, returns enabled providers
│   │   ├── deepgram-nova2.ts        Current production (batch + streaming)
│   │   ├── deepgram-nova3.ts        Newer Deepgram model
│   │   ├── openai-whisper.ts        gpt-4o-transcribe + gpt-4o-mini + whisper-1
│   │   ├── groq-whisper.ts          whisper-large-v3 @ Groq
│   │   └── elevenlabs-scribe.ts     Scribe v1
│   ├── metrics/
│   │   ├── normalize-arabic.ts      ة↔ه, ي↔ى, diacritics, hamza, digits
│   │   ├── wer.ts                   Word Error Rate (Levenshtein)
│   │   └── cer.ts                   Character Error Rate
│   ├── audio.ts                     WAV reading, μ-law encoding, ffprobe wrapper
│   ├── runner.ts                    Orchestrates provider × sample × mode
│   └── report.ts                    Markdown + JSON output
├── bin/
│   ├── bench.ts                     CLI: pnpm bench
│   └── seed-tts.ts                  CLI: pnpm seed:tts
└── fixtures/
    ├── seeds/egyptian-medical.json  20 hand-curated complaints
    ├── samples.json                 Generated by seed-tts (or hand-edited)
    └── audio/                       Audio files (gitignored)
```

## Pricing assumptions

| Provider | Default cost | Override env var |
|---|---|---|
| Deepgram Nova-2 (batch & streaming) | $0.0043/min | `DEEPGRAM_PRICE_PER_MIN` |
| Deepgram Nova-3 | $0.0043/min | `DEEPGRAM_PRICE_PER_MIN` |
| OpenAI gpt-4o-transcribe | $0.006/min | hard-coded |
| OpenAI gpt-4o-mini-transcribe | $0.003/min | hard-coded |
| OpenAI whisper-1 | $0.006/min | hard-coded |
| Groq whisper-large-v3 | $0.111/hr ≈ $0.00185/min | `GROQ_PRICE_PER_HOUR` |
| ElevenLabs Scribe | $0.008/min (Creator tier) | `ELEVENLABS_SCRIBE_PRICE_PER_MIN` |

Set your own if you have enterprise pricing. All costs in the report are USD.

## CLI flags

```
--mode batch|streaming|both   Benchmark mode (default: batch)
--samples PATH                Custom samples.json (default: fixtures/samples.json)
--filter SUBSTRING            Only run providers matching this substring
--out PATH.md                 Custom output path (also writes .json sibling)
```

## What to do with the results

The report's **Recommendation** section will list the best provider for each use case:

1. **Telehealth post-call transcription** (`apps/web/lib/telehealth/transcribe.ts` — currently Deepgram Nova-2 batch) → pick the lowest-WER batch provider you can afford.

2. **Live phone-call STT** (`apps/web/lib/phone/deepgram.ts` — currently Deepgram Nova-2 streaming) → pick the streaming provider with the best WER **and** first-final latency < 800ms. Anything slower will feel laggy in conversation.

3. **Cost-conscious bulk workloads** → look for the WER/cost inflection point. Groq is usually 30× cheaper than OpenAI for similar Whisper quality.

Once a winner emerges, swapping it in is a 1-day change: implement the provider in `apps/web/lib/phone/<provider>.ts` matching the existing `DeepgramConnection` interface, then update the factory call in `call-session.ts`.

## Limitations

- **No streaming for OpenAI / Groq / ElevenLabs.** Their APIs are batch-only as of mid-2025. The streaming table will only show Deepgram variants until others release streaming.
- **TTS seed audio is too clean.** Replace with real Twilio recordings for trustworthy numbers.
- **Single-speaker assumption.** Real calls have crosstalk; this harness doesn't measure diarization quality.
- **English code-switching not separately scored.** WER is computed on the full transcript regardless of language.
